# Тестирование реакции водителя АТС
Desktop приложения для определения времени реакции водителя на опредлённый раздражитель, которая представляет собой клиентскую часть (приложение с тестами) и часть адмистратора (приложение для контролем за пользователями и тестовыми сессиями).
Основная ценность разработки - снижение рисков ДТП.

## Файл конфигурации `app\config.json`

Приложения, работающие с пользователями (гибрид, клиент с тестами, администратор), при запуске читают файл `app\config.json` относительно рабочей директории процесса — то есть из папки `app` рядом с местом запуска программы. Без него приложение падает с ошибкой «Файл конфигурации для ключей не найден». Генератору кода этот файл не нужен.

Файл содержит секретный ключ, поэтому в репозиторий **не коммитится** (`app/config.json` добавлен в `.gitignore`). Шаблон лежит в [`docs/config.example.json`](docs/config.example.json):

```json
{
  "cryptography": {
    "secret_key": "ЗАМЕНИТЕ_НА_КЛЮЧ_32_СИМВОЛА_HEX",
    "algorithm": "AES",
    "transformation": "AES/ECB/PKCS5Padding"
  },
  "program_data": {
    "name": "Тест на реакцию",
    "version": "1.0.0",
    "number": "ЗАМЕНИТЕ_НА_НОМЕР_ПРОГРАММЫ"
  }
}
```

### Поля

| Поле | Назначение |
|---|---|
| `cryptography.secret_key` | Ключ шифрования ФИО и пола пользователей в базе данных. |
| `cryptography.algorithm` | Алгоритм для `javax.crypto.spec.SecretKeySpec` (например, `AES`). |
| `cryptography.transformation` | Строка для `javax.crypto.Cipher.getInstance` (например, `AES/ECB/PKCS5Padding`). |
| `program_data.name` / `version` / `number` | Название, версия и уникальный номер программы — выводятся на экране «О программе». |

### Откуда брать значения

**Если программа уже где-то развёрнута и в базах есть пользователи** — не генерируйте ничего заново: скопируйте `app\config.json` целиком с компьютера, где программа уже работает (или от администратора/разработчика, который её устанавливал). Ключ и параметры шифрования невозможно восстановить из кода или из базы.

**Если это первая установка (базы пустые)** — заполните файл так:

| Поле | Откуда взять |
|---|---|
| `secret_key` | Запустите «Генерация уникального кода» (`./gradlew :desktop-application:generate-code-application:run`), оставьте «Размер ключа (бит)» = **128** и нажмите генерацию. Скопируйте значение из поля «Ключ» (32 символа). |
| `number` | Из того же окна генератора — поле «Номер программы» (64 символа). Генерировать можно только один раз за запуск, поэтому скопируйте оба значения сразу. |
| `algorithm` | Впишите `AES`. Генератор это поле не заполняет. |
| `transformation` | Впишите `AES/ECB/PKCS5Padding`. Режимы с вектором инициализации (CBC, GCM и т.п.) **не подходят**: код не сохраняет IV, и данные потом не расшифруются. |
| `name` | Произвольное название, которое будет показано на экране «О программе». Удобно взять `packageName` приложения из его `build.gradle.kts` (например, `Тест на реакцию`). |
| `version` | Версия для экрана «О программе» — `packageVersion` из `build.gradle.kts` приложения (сейчас `1.0.0`). |

Почему именно 128 бит: ключ используется как строка — приложение берёт байты hex-строки как есть, а не декодирует её. Для AES длина строки `secret_key` должна быть **ровно 16, 24 или 32 символа**. Генератор выдаёт строку длиной `размер / 4`, поэтому допустимы только размеры **64, 96 или 128**. При другой длине шифрование упадёт с ошибкой `Invalid AES key length`.

После этого один и тот же файл разложите на все компьютеры, где установлены приложения.

### Совместимость с существующими данными

Все приложения, работающие с одной базой (в том числе по сети), должны использовать **одинаковые** `secret_key`, `algorithm` и `transformation`. Если базы уже заполнены, используйте тот же ключ, которым они были зашифрованы: с другим ключом ранее сохранённые ФИО пользователей не расшифруются.

### Куда класть файл

- **Установленное приложение:** `<папка, из которой запускается программа>\app\config.json`.
- **Запуск из Gradle** (`./gradlew :desktop-application:<приложение>:run`): рабочая директория — папка модуля, т.е. `desktop-application\<приложение>\app\config.json`.
- Путь в коде записан с обратным слешем (`app\config.json`), поэтому корректно работает только на Windows.
